# Häufige Fragen

🇬🇧 [English version](FAQ)

**Wie verschiebe ich einen Tab frei und ändere seine Größe?**
Tabs in der Leiste haben feste Plätze. Frei verschieben und in der Größe ändern lassen sich **Fenster**. Mach aus dem Tab ein Fenster (*Bearbeiten → Anzeige: Eigenes Fenster*), öffne den Chat (**T**) und zieh das Fenster an der Titelleiste bzw. an der Ecke unten rechts. Siehe [Chatfenster und Filter](Chatfenster-und-Filter).

**Eine Nachricht landet im falschen Tab. Was tun?**
Im Tab-Editor gibt es einen **Live-Test**: Kopier die Zeile aus dem Chat hinein, dann siehst du sofort, ob sie passt. Denk daran: Der *erste* passende Kanal in der Liste gewinnt, und Filter von Fenstern haben Vorrang vor allen Tabs.

**Ich habe einen Filter erstellt und will ihn wieder loswerden.**
Einstellungen (**K**) → beim Fenster/Tab **Bearbeiten → Zusätzliche Nachrichten …** → Regel mit **✕** löschen. Oder das ganze Fenster in der Tab-Liste mit **✕** löschen und **Speichern**.

**Das Fenster ist weg / liegt außerhalb des Bildschirms.**
*Bearbeiten → Fenster … → Position und Größe zurücksetzen*. Prüf außerdem, ob *Bei geschlossenem Chat* auf *Nur bei offenem Chat* steht.

**Alte Nachrichten erscheinen doppelt.**
Wahrscheinlich speichert noch eine andere Mod den Chat. Schalte unter *Kanäle & Verlauf → Nachrichten speichern* eine der beiden Funktionen aus.

**Beim Klick auf einen Tab kommt eine Fehlermeldung vom Server.**
Der *Wechsel-Befehl* des Tabs (z. B. `/ch global`) gibt es auf diesem Server nicht. Pass ihn im Tab-Editor an, lass ihn leer oder schalte *Kanäle & Verlauf → Kanal beim Tab-Klick wechseln* aus.

**Ich will auf einem Server den normalen Chat.**
Einstellungen → *Server-Profile* → beim Server **ChatLanes** ausschalten.

**Läuft ChatLanes mit der CubesideMod?**
Ja.

**Wo melde ich Fehler oder schlage etwas vor?**
In den [Issues](https://github.com/0eiki0/chatlanes/issues) auf GitHub.
